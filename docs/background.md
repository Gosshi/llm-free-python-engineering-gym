# Background and purpose

## 現在地

ユーザーはLINEヤフーでソフトウェアエンジニアとして勤務している。転職では現職から
年収を150万円以上上げることを目標に、国内大手、外資系、海外企業を含めて検討する。
ICに限らず、シニアエンジニア、テックリード、将来的なエンジニアリングマネージャー
候補も選択肢である。福利厚生、勤務地、出社頻度、待遇の釣り合いを重視する。

英語環境も候補に含める。大学時代のTOEICは745点で、3〜5歳を米国で過ごした経験が
あり、英語そのものへの強い苦手意識はない。

## なぜ訓練が必要か

現在、実装のほぼ100%でLLMを利用している。このこと自体を問題と決めつけるのでは
なく、LLMなしで何ができるか、どこで停止するか、生成コードを自力で評価できるかを
事実ベースで把握する必要がある。

特に、Python文法・標準ライブラリの想起、要件を処理単位に分解すること、生成コードの
品質評価、デバッグ、テスト、例外処理、設計の説明に不確実性がある。資格や正式な
ピープルマネジメント経験がないことも踏まえ、職位の自己評価を単一の印象ではなく、
複数の実装記録と説明記録で補強する。

## 技術経験と検証対象

個人開発ではPython、FastAPI、PostgreSQL、REST API、TypeScript、Next.js、Supabaseを
扱った経験がある。ただし個人開発でもLLMへの依存は大きい。本リポジトリでは、LLMを
使わない制限時間付き課題を通じて、要件理解、問題分解、Python実装、データ構造、
責務分割、型、読解、デバッグ、テスト、エラー処理、データモデリング、API設計、
セキュリティ、性能感覚、設計トレードオフ、技術文章、優先順位付けを確認する。

目標は「LLMを使わないこと」そのものではない。LLMを使う状況でも、実装を判断・修正・
説明できる基礎を回復し、転職活動で再現性のある強みと学習課題を説明できるようにする
ことである。
